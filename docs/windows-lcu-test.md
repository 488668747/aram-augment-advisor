# Windows 选人识别测试

安装包：`dist/aram-augment-advisor-0.2.0-win-x64-setup.exe`，适用于 Windows 10/11 x64。

1. 将安装包复制到 Windows 电脑，双击安装并打开“海克斯大乱斗助手”。不用安装 Node.js，也不用先同步数据，包内已有 16.21.5 统计数据。
2. 在同一台电脑启动国服 League Client，登录并进入大乱斗选人界面。
3. 查看应用里的 League Client 状态：预期显示“已连接，正在选人”，当前英雄与游戏客户端一致。
4. 更换英雄（例如重新随机或交换），确认应用的英雄名字、头像、胜率和海克斯榜单跟随更新。默认每 1.5 秒轮询一次。
5. 返回大厅，确认连接状态更新为当前阶段。

## 游戏内三卡浮窗

完成英雄识别测试后进入实际对局，开启主应用的本地识别浮层并选择游戏所在显示器。出现三个海克斯选项时，先尝试默认 16:9 标题区域；无法识别则点击截图校准，只框名称文字，依次框选左、中、右并保存。顶部浮窗应对应三张卡片显示当前英雄的胜率与场次，刷新后应更新；取消识别或返回大厅应隐藏。支持 F8 或应用按钮手动触发。

模型随安装包内置，不需要安装 Python 或联网下载。详细校准步骤和限制见 [本地 OCR 与浮窗](local-ocr-overlay.md)。

若没有跟随，反馈应用里的 League Client 状态、游戏安装目录，以及是否通过 WeGame 启动。当前版本自动查找常见目录和进程命令行里的 `--install-directory`；未覆盖的安装方式可能需要补充发现逻辑。

测试包尚未签名。已在 macOS 完成 Windows x64 构建、安装包归档完整性、包内源码与全部 222 个数据文件校验、离线 OCR 模型 SHA-256 与打包 worker/WASM 路径核验；实际使用打包资源完成了中文字图识别。模拟 LCU、真实 OCR、三槽窗口、校准与失败暂停测试已通过；尚未在真实 Windows 国服客户端验证安装、屏幕截图及独占全屏表现。

统计数据已内置；英雄、海克斯和装备图标目前仍通过 CDN 联网加载。本版本包含应用内分类海克斯胜率、五六件出装，以及游戏内本地 OCR/顶部三卡胜率浮窗。出装只在应用内展示，尚未计算已选海克斯之间的联动胜率。

## 构建

```bash
npm ci
npm run data:sync
npm test
npm run verify:overlay
npm run dist:win -- --publish never
```

脚本显式指定 `--x64`，避免 Apple 芯片 Mac 交叉构建时默认产生 Windows ARM64 包。安装包只收录 `src/`、运行配置及内置数据，不含开发测试文件。
