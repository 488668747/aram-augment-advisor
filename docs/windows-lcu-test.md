# Windows 选人识别测试

安装包：`dist/aram-augment-advisor-0.1.0-win-x64-setup.exe`，适用于 Windows 10/11 x64。

1. 将安装包复制到 Windows 电脑，双击安装并打开“海克斯大乱斗助手”。不用安装 Node.js，也不用先同步数据，包内已有 16.21.5 统计数据。
2. 在同一台电脑启动国服 League Client，登录并进入大乱斗选人界面。
3. 查看应用里的 League Client 状态：预期显示“已连接，正在选人”，当前英雄与游戏客户端一致。
4. 更换英雄（例如重新随机或交换），确认应用的英雄名字、头像、胜率和海克斯榜单跟随更新。默认每 1.5 秒轮询一次。
5. 返回大厅，确认连接状态更新为当前阶段。

若没有跟随，反馈应用里的 League Client 状态、游戏安装目录，以及是否通过 WeGame 启动。当前版本自动查找常见目录和进程命令行里的 `--install-directory`；未覆盖的安装方式可能需要补充发现逻辑。

测试包尚未签名。已在 macOS 完成 Windows x64 构建、安装包归档完整性、包内源码与全部 222 个数据文件校验，以及模拟本地 HTTPS LCU 的英雄切换验证；尚未在真实 Windows 国服客户端验证安装、进程发现和连接。

统计数据已内置；英雄、海克斯和装备图标目前仍通过 CDN 联网加载。本版本包含应用内分类海克斯胜率和五六件出装展示，不包含游戏内 OCR/胜率浮窗。

## 构建

```bash
npm ci
npm run data:sync
npm test
npm run dist:win -- --publish never
```

脚本显式指定 `--x64`，避免 Apple 芯片 Mac 交叉构建时默认产生 Windows ARM64 包。安装包只收录 `src/`、运行配置及内置数据，不含开发测试文件。
