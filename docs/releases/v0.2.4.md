# v0.2.4 Windows 测试版

针对“英雄联盟客户端已运行，但助手显示未检测到”的问题，补充国服目录发现和手动配置兜底。

- 自动检测 LeagueClient.exe 与 LeagueClientUx.exe 的实际程序路径，同时检查游戏根目录和 LeagueClient 子目录中的连接文件。
- 新增客户端目录输入、选择目录、保存并检测、重新检测及清除配置；配置保存在本机，重启后保留。
- 支持直接粘贴 LeagueClient.exe、LeagueClientUx.exe 或 lockfile 的完整路径；客户端尚未运行时也能保存有效安装目录。
- 分别提示进程信息读取失败、连接文件缺失、读取权限不足和接口尚未就绪，不再全部显示成“未检测到”。
- 自动发现优先，手动目录用作兜底；只保存目录，不保存连接令牌。
- 自动候选文件失效时继续尝试其他候选和手动目录；切换连接来源或客户端目录时清空旧英雄与浮窗识别结果。

安装后启动并登录英雄联盟客户端。若仍未自动连接，在首页选择“英雄联盟”安装目录或其中的 LeagueClient 目录，点击“保存并检测”。不要选择 WeGame 启动器目录。如果客户端以管理员身份启动，请让助手使用相同权限。

已在 macOS 验证 Windows 路径测试、真实应用配置界面与本地模拟 LCU、目录保存、英雄跟随及错误提示；Windows 安装包由 GitHub Actions 构建并校验。真实国服连接和屏幕识别仍需 Windows 实机复测。本版为未签名测试版。
