修复 Windows ASAR 资源校验的路径分隔符兼容问题。

修复跨平台文本资源校验的换行兼容，并增加构建失败诊断；保留二进制模型与统计数据的严格 SHA-256 校验。

本次修复依赖锁文件中的私有 npm 镜像地址，改用公开 npm，以支持 GitHub Windows Runner 构建。功能与 0.2.0 一致。

面向 Windows 10/11 x64 的测试安装包。下载下方 `aram-augment-advisor-0.2.3-win-x64-setup.exe` 并安装，无需安装 Node.js 或 Python。

本版支持：

- 通过本地 LCU 自动跟随选人英雄，并在对局中再次核实最终英雄。
- 本地 OCR 识别左、中、右三个海克斯名称，使用顶部透明浮窗显示当前英雄对应胜率与场次。
- 显示器选择、名称区域截图校准、F8 手动识别；退出对局或关闭识别后隐藏浮窗。
- 应用内按棱彩、黄金、白银分别排行，以及去重后的五六件出装组合。
- 内置统计 JSON 与离线 OCR 模型，可在应用内手动同步统计数据；不上传截图或战绩。

先启动助手和国服客户端，进入选人界面检查英雄是否跟随。进入游戏后开启本地识别，选择游戏所在显示器；若默认区域识别不准，在应用中点击截图校准，只框选三个名称文字。出装仅在主应用展示。

这是未签名测试版，真实国服客户端、多显示器缩放和独占全屏兼容性仍需实测。当前胜率是英雄＋单海克斯的样本统计，尚未计算已选海克斯之间的联动；图标仍需联网加载。

统计数据直接来自第三方 ARAMGG 接口，部分字段标注腾讯国服、部分海克斯胜率标注全球上传样本，不能统称为官方全球统计。

附件还提供 SHA-256 校验文件及 `release-info.json`，记录实际构建版本、提交、数据版本与 OCR 模型语言。该 Release 标记为预发布，便于小范围测试。
