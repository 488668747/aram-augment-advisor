# v0.2.6 Windows 测试版

针对“英雄联盟客户端已运行，但助手显示未检测到”的问题，补充国服目录发现和手动配置兜底。

- 自动检测 LeagueClient.exe 与 LeagueClientUx.exe 的实际程序路径，同时检查游戏根目录和 LeagueClient 子目录中的连接文件。
- 新增客户端目录输入、选择目录、保存并检测、重新检测及清除配置；配置保存在本机，重启后保留。
- 支持直接粘贴 LeagueClient.exe、LeagueClientUx.exe 或 lockfile 的完整路径；客户端尚未运行时也能保存有效安装目录。
- 分别提示进程信息读取失败、连接文件缺失、读取权限不足和接口尚未就绪。
- 自动候选连接失败后继续尝试其他候选及手动目录；切换来源时丢弃旧英雄与未完成的 OCR 结果。
- 放宽 Windows 首次进程查询到 15 秒，避免冷启动时提前报告扫描失败。
- 增加 Windows 分支检查和公开测试失败摘要；只保存客户端目录，不保存连接令牌。

下载 `aram-augment-advisor-0.2.6-win-x64-setup.exe` 安装后，启动并登录英雄联盟客户端。若仍未自动连接，在首页选择“英雄联盟”安装目录或其中的 LeagueClient 目录，点击“保存并检测”。不要选择 WeGame 启动器目录。如果客户端以管理员身份启动，请让助手使用相同权限。

本地模拟 LCU、真实应用配置界面、英雄跟随和 OCR/浮窗验证已通过；Windows Runner 负责平台测试、构建和包内资源校验。真实国服连接和屏幕识别仍需 Windows 实机复测。本版为未签名测试版。

当前海克斯胜率仍是英雄＋单海克斯的统计，尚未包含已选海克斯之间的联动。统计接口为第三方 ARAMGG 数据源，部分字段标注腾讯国服、部分海克斯标注全球上传样本，不能统称为官方全球统计。图标仍需联网加载。
