# v0.2.7 Windows 测试版

修复客户端已运行但助手提示“LCU lockfile 格式无效”时，连接链路只依赖连接文件的问题。

- 优先解析运行中的 LeagueClientUx/LeagueClient 进程启动参数，读取本地接口端口与认证信息；无需先存在 lockfile。
- 保留连接文件兜底，兼容 UTF-8 BOM 与 UTF-16 LE/BE，并补查 LeagueClient 父目录。
- 连接文件为空、无效或接口不可用时，继续尝试本机客户端日志；限制读取文件数量与内容大小。
- 连接请求只发送到 127.0.0.1；不上传日志，不显示或保存认证令牌。
- 保留手动目录配置、英雄跟随、应用内推荐与本地 OCR 浮窗。

安装新版后保留原来的英雄联盟目录，启动并登录客户端，再点击“重新检测”。若客户端以管理员身份运行，请让助手使用相同权限。不要发送 lockfile 或客户端日志原文，其中可能包含临时认证信息。

已通过本地回归测试及完整应用“空 lockfile＋日志兜底”的模拟连接验证。Windows Runner 负责平台测试、构建和包内资源校验；真实国服客户端仍需实机复测。本版为未签名测试版。
